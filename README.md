# 山口県立高校再編の意思決定過程

山口県が公表した公式資料をもとに、県立高校再編について、何が提案され、県民意見や審査を経て、何が最終決定されたかをたどる静的Webアプリケーションです。

**公開サイト:** https://yyy-yuichi.github.io/yamaguchi-highschool-pubcom/

## 確認できること

- 学校ごとの変更内容: 27件
- 素案と最終計画の差分: 111件
- 県民意見と県の回答: 382意見・78回答・78グループ
- 公表・審査・計画策定までの時系列: 11件
- パブリックコメント本文: 物理3〜39ページの37ページ分

学校名は自由入力ではなく、公式資料で確認できた学校を固定ボタンで表示します。本文、資料ページ、論点、回答グループと組み合わせて絞り込めます。

## 利用上の注意

このサイトは、再編への賛否、計画変更の原因、意見の代表性を自動判定するものではありません。県民意見の件数は、回答者数、賛否票、県民全体を代表する調査結果を意味しません。

最新情報と文脈は、各画面からリンクしている山口県等の公式資料で確認してください。
