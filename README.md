# 山口県立高校再編の意思決定過程

山口県が公表した公式資料をもとに、県立高校再編について次の情報を確認できるWebサイトです。

- 学校ごとの変更内容
- 素案と最終計画の差分
- 県民意見と県の考え方
- 公表・審査・計画策定までの時系列

## 利用上の注意

このサイトは、再編への賛否、計画変更の理由、意見の代表性を自動判定するものではありません。
最新情報と文脈は、各画面からリンクしている山口県等の公式資料で確認してください。

県民意見の件数は、回答者数、賛否票、県民全体を代表する調査結果を意味しません。

## ファイル構成

- `docs/index.html`: Webサイト
- `docs/app.js`: 表示と操作
- `docs/styles.css`: レイアウトとデザイン
- `docs/data/public_experience.json`: 公開画面で使用するデータ
